1. **Card target line vocabulary.** "Target £60 · withheld · evidence
   withdrawn" — the last surface of the old seven-words problem: raw
   `withheld`/`withdrawn`, no gloss tooltip, and "withdrawn" can read as *the
   seller withdrew*. Everywhere else the family phrase appears; here it doesn't.

   "receipt_predates_correction", "source_revision_superseded", "freshness:
   freshness_unvalidated", "unknown; not_applicable." are shown as plain text
   without the "Technical state: …" tooltips the other terms get.
3. **Multi-correction verbosity.** With two corrections the hero shows two
   "dial" rows ("dial: salmon (was: mint, as listed)" + "dial: Blue (was:
   salmon, as listed)") and the banner lists both steps — accurate as a chain,
   but the intermediate row can momentarily read as a second current value.
   (Anticipated in the diagnosis's copy-deviation notes; no fix proposed.)
4. **Tracking's "Tracked watch" block shows `dial: mint`** (the retained
   observed configuration) while the hero shows the corrected value — honest
   retained evidence, but unexplained on that screen; a buyer flipping between
   the two screens sees mint vs Blue with nothing saying which is which.
5. **History assessment blocks don't name the cause.** The observation rows say
   "withdrawn after correction", but the eight "Historical assessment" blocks
   still don't say *why* they became historical (the F4 summary covers this at
   the moment of saving, so it is a residual, not a gap).
6. Minor: feed card ordering rotated between loads (the Addiesdive card moved
   from last to first mid-session) — harmless but slightly disorienting when
   following position-based guidance.

None of these blocked the walk; all are recorded, not fixed (docs-only run).
