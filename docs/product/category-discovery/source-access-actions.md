## What browser repair cannot supply

Browser content/session fixes can expose public fields on permitted routes. They cannot supply API entitlements, agent signing identity, provider permission for restricted uses, or archive/republication rights. A one-off personal buying investigation and an ongoing category-price database are different uses; success at the former does not establish authority for the latter. Reuse existing adapters rather than create alternative scrapers to bypass these prerequisites.
